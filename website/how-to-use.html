How to use Cluegent

Watch the full walkthrough, then follow the steps below to launch Cluegent, move the floating assistant, ask typed prompts, listen to conversations, and capture screenshots for coding answers.

Step by step

Use every mode from the floating assistant

Cluegent stays as a movable overlay, so you can keep it anywhere on the screen while working in meetings, browsers, editors, or coding platforms.

01

Switch to Undetectable and start Cluegent

Click the Detectable toggle to enable private overlay mode, then click Start Cluegent.

02

Move the assistant anywhere

The floating bar can be positioned wherever it is comfortable while you continue using other apps.

03

Use listening mode

Click Start listening. Cluegent shows a rolling transcript as the conversation happens.

04

Submit the live context

Press Ctrl + Enter to get an AI response based on the transcript.

05

Ask with type mode

Type your question directly in the input box, then submit with the arrow or Ctrl + Enter.

06

Read the answer in place

The response appears inside the same overlay, so you do not have to leave your workflow.

07

Capture a screenshot

Use Ctrl + [ to attach the visible screen when you need help with code or visual context.

08

Get a code solution

Cluegent reads the screenshot, explains the approach, and gives a practical solution.

09

Apply and continue

Use the answer in your editor, keep the assistant movable, and continue without breaking focus.
