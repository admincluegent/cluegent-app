Current stack Already live

Production direction, not a prototype fantasy.

Speech to text

AssemblyAI streaming

Realtime transcript for the live rolling bar with Firebase-issued temporary access tokens.

Text answers

DeepSeek primary

Text-only answer path uses DeepSeek first, with Groq ready as a fallback route.

Screenshot answers

Gemini 2.5 Flash-Lite primary

Image-backed prompts route to Gemini first, then fall back to Llama 4 Scout on Groq.

Backend

Firebase Functions + Firestore

Auth, usage limits, secrets, provider selection, and tracking are already cloud-managed.
