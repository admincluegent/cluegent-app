Frequently asked questions

What is Cluegent?

Cluegent is a desktop AI copilot for permitted live meetings and calls. It listens when you ask it to, keeps rolling context, and gives real-time answers from transcript, typed prompt, and screen context.

Does Cluegent join my meeting?

No. Cluegent runs as a desktop app and does not install a browser extension into the call.

Which platforms does it work with?

It is designed for desktop calls and screen workflows, including Google Meet, Zoom, Microsoft Teams, Slack Huddles, browser tabs, coding editors, and documents.

Does Cluegent work for coding interviews?

Yes. Use screenshot mode to attach a visible coding problem, error, or shared screen. Cluegent can help with the approach, edge cases, tradeoffs, and a clean explanation.

Can Cluegent use my resume for answers?

Yes. Open Settings, go to Customize, and add resume context so Cluegent can shape answers around your projects, skills, stack, and experience.

Will Cluegent show during screen sharing?

Cluegent includes a private desktop overlay for your own workspace. Behavior can vary by app, operating system, and permissions, so follow meeting rules, consent requirements, workplace policies, and applicable law.

Is my data safe?

Cluegent is built on privacy. Recent meeting history and saved local context stay on your machine, while active transcription, prompt, and screenshot requests are processed only when you use those features.

Is Cluegent free to try?

Yes. Cluegent is free to start, and the download page points you to the current Windows and macOS builds.

Can I use it as an AI meeting copilot too?

Yes. Cluegent also works for permitted live meetings, client calls, product reviews, and technical discussions where you want live context and quick answers.
