## Short Description

Cluegent is a desktop AI assistant for permitted live interviews, coding rounds, and technical meetings. It helps job seekers and developers with live context, typed prompts, screenshot-aware answers, resume-aware customization, and quick action buttons.

## Long Description

Cluegent is a private desktop AI assistant for job seekers, freshers, and developers who need structured help during permitted live interviews, coding rounds, and technical calls.

Instead of switching between a meeting app, coding platform, browser, and generic chatbot, Cluegent keeps support inside a desktop overlay. Users can start listening when allowed, type direct prompts, attach screenshots for coding or screen questions, add resume context, and use quick action buttons for common response styles.

Cluegent is useful for:

- AI interview assistance
- Coding interviews
- Freshers and job seekers
- Developer interviews
- Zoom, Google Meet, and Teams interviews
- Resume-aware answer support
- Screenshot-based coding and debugging questions
- Permitted technical meetings

Cluegent should be used only where AI assistance, transcription, screenshots, and desktop overlays are permitted.

## Founder Note

Cluegent was built because live interviews are not only a knowledge problem. They are a timing and context problem. Candidates may understand a topic but still freeze when the question is live, the screen changes, or the interviewer adds a constraint. Cluegent helps users stay structured and focused in permitted workflows.
