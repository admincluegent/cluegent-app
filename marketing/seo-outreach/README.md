## Posting Rules

- Do not spam the same text everywhere.
- Add value first, then mention Cluegent naturally.
- Avoid absolute claims like "100% undetectable".
- Use safer wording: "private overlay designed to stay out of standard screen sharing".
- Use only one link per Reddit/Quora answer unless the platform allows more.
- Track every submission in `backlink-tracker.csv`.

## UTM Links

Use UTM links when posting outside the website:

```text
?utm_source=SOURCE&utm_medium=organic_outreach&utm_campaign=seo_growth
```

Examples:

```text
https://www.cluegent.com/best-ai-interview-assistant-india/?utm_source=reddit&utm_medium=organic_outreach&utm_campaign=seo_growth
https://www.cluegent.com/download/?utm_source=producthunt&utm_medium=organic_outreach&utm_campaign=seo_growth
```
