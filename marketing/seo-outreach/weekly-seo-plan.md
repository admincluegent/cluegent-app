# Four-Week SEO and Outreach Plan

## Week 1: Foundation Backlinks

Goal: Get the first 5-10 branded backlinks and referral clicks.

Tasks:

1. Submit Cluegent to Product Hunt.
2. Post founder story on Indie Hackers.
3. Submit to SaaSHub.
4. Submit to AlternativeTo.
5. Submit to BetaList.
6. Add Cluegent to 3 AI directories.
7. Track every URL in `backlink-tracker.csv`.

Priority target pages:

- https://www.cluegent.com/
- https://www.cluegent.com/best-ai-interview-assistant-india/
- https://www.cluegent.com/ai-interview-assistant-for-developers/

## Week 2: Helpful Community Answers

Goal: Start long-tail referral traffic without spam.

Tasks:

1. Answer 3 Quora questions about AI interview assistants.
2. Answer 3 Reddit questions only where self-promotion is allowed or genuinely useful.
3. Publish a Dev.to article based on coding interview AI.
4. Publish a Medium article based on AI interview assistant vs ChatGPT.

Priority target pages:

- https://www.cluegent.com/ai-interview-assistant-vs-chatgpt/
- https://www.cluegent.com/ai-interview-assistant-for-coding-interviews/
- https://www.cluegent.com/affordable-ai-interview-assistant/

## Week 3: Comparison Traffic

Goal: Capture users comparing competitors.

Tasks:

1. Share Cluegent vs LockedIn AI article.
2. Share Cluegent vs Parakeet AI article.
3. Submit to alternative directories using the competitor alternative angle.
4. Request indexing for new competitor pages if not already indexed.

Priority target pages:

- https://www.cluegent.com/best-lockedin-ai-alternatives/
- https://www.cluegent.com/best-parakeet-ai-alternatives/
- https://www.cluegent.com/chiku-ai-alternative/

## Week 4: Conversion Improvement

Goal: Convert traffic into downloads.

Tasks:

1. Review GA4 download clicks by page.
2. Review Search Console impressions by page.
3. Improve pages with impressions but low CTR.
4. Add demo video to homepage and download page.
5. Add Microsoft Store troubleshooting page if install issues continue.

Metrics to check:

- Search Console impressions
- Search Console clicks
- Average position
- GA4 `download_click`
- GA4 `free_trial_click`
- Microsoft Store install feedback
